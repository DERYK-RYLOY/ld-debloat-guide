# Config key reference

Files LDPlayer owns. Values shown are the playbook's reference profile. **Never edit while the emulator is running** — LDPlayer rewrites these files on launch and shutdown.

## `vms\config\leidians.config` (global)

| Key | Meaning | Reference value |
|---|---|---|
| `reportPCInfoTime` | Last hardware-report timestamp | `20990101` (pin) |
| `adLoadtime` | Next ad payload load time | `4102444800` (2100) |
| `nextCheckupdateTime` | Next update check | `4102444800` (2100) |
| `isSSD` | Host disk type hint | `true` |
| `strp` | Update/channel string | build-specific — leave as-is |
| `languageId`, `productLanguageId` | Guest UI locale | `en_US` or your locale |

## `vms\config\leidian0.config` (instance 0)

| Key | Meaning |
|---|---|
| `propertySettings.phoneModel` | Guest device model (identity profile) |
| `propertySettings.phoneManufacturer` | Guest manufacturer |
| `propertySettings.phoneIMEI`, `phoneIMSI`, `phoneSimSerial` | Simulated telephony identity |
| `propertySettings.phoneAndroidId` | Android ID used by apps |
| `propertySettings.macAddress` | Guest NIC MAC |
| `statusSettings.sharedApplications` / `sharedPictures` / `sharedMisc` | Host shared folders |
| `basicSettings.width/height`, `realWidth/realHeight` | Window / framebuffer size |
| `networkSettings.networkEnable` | Guest networking switch |

## `vms\leidian0\leidian.vbox` (VM definition)

| Element | Meaning | Reference |
|---|---|---|
| `Memory RAMSize` | Guest RAM in MB | `3072` |
| `CPU count` | vCPUs | `3` |
| `Machine name` / `uuid` | Instance identity | generated — do not change |
| `HardDisk` entries | System/data disk paths | generated — do not hand-edit paths |
| `ExtraDataItem VBoxInternal/PDM/Devices/fastpipe/Path` | Display bridge DLL | vendor-provided |
| `Network Adapter MACAddress` | Guest NIC MAC | keep consistent with instance config |

## `device.ini` (host capability snapshot)

| Key | Meaning |
|---|---|
| `display` | Host GPU used for rendering |
| `vt` | Virtualisation support flag |
| `cpu` | Host CPU model |
| `memory` | Host RAM |

Generated by LDPlayer — informational, not a tuning surface.

## Safe editing procedure

```powershell
# 1. stop the emulator
Get-Process dnplayer -ErrorAction SilentlyContinue | Stop-Process -Force

# 2. back up the file
Copy-Item 'C:\LDPlayer\LDPlayer9\vms\config\leidian0.config' `
          'C:\LDPlayer\LDPlayer9\vms\config\leidian0.config.bak' -Force

# 3. edit, then relaunch and verify
& 'C:\LDPlayer\LDPlayer9\ldconsole.exe' launch --index 0
powershell -NoProfile -ExecutionPolicy Bypass -File C:\LDPlayer\verify-debloat.ps1
```

## Do not edit

`system.vmdk`, `data.vmdk`, `.r0` modules, `gpu\*.dll`, `vbox64\*.dll`, registry COM entries. Those are vendor binaries and VM images.
